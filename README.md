# えいたんご ともだち

英単語学習アプリです。**スペル・発音・使い方** の3つの面から、楽しく・確実に覚えられるようにしています。

ホーム画面でレベルを選べます。

| レベル | 語数 | 内容 |
| --- | --- | --- |
| 🎒 小学生 | 317語 | 毎日つかう、かんたんな単語（きほん118語＋ステップ2の199語）。カタカナの読みかたつき |
| 📘 中学生 | 152語 | 学校・気持ち・動詞・頻度の副詞・季節や世界・生活・自然 |
| 📗 高校生 | 99語 | 論理的な文章でよく使う動詞・社会や学問の名詞・形容詞・つなぎ言葉 |
| 🎓 大学生 | 80語 | 論文や講義で使うアカデミックな語彙 |

レベルを切りかえても、それぞれの記録はのこります。

ブラウザで `index.html` をひらくだけで動きます（インストール不要・サーバー不要）。

## できること

| 画面 | 内容 |
| --- | --- |
| 🌟 きょうのレッスン | 新しいことば（1回3語まで）をカードで覚えて、すぐにクイズでたしかめる。前に覚えたことばの復習もまざる。きほんの118語が終わると、ステップ2の199語が出てくる |
| 🎮 あそぶ | いみクイズ／きいてクイズ／スペル／つかいかた／ミックスを、なかま（カテゴリ）をえらんで自由に練習 |
| 📚 ことば ずかん | 全部のことばをカテゴリごとに見て、音声と例文を確認 |
| 🏅 シールちょう | 覚えたことばがシールになってたまる。マスターすると金のシール |

### 4つの問題タイプ

- **いみクイズ**: 英単語を見て・聞いて、意味（絵文字＋日本語）を選ぶ
- **きいてクイズ**: 音声だけを聞いて、英単語を選ぶ（ゆっくり再生あり）
- **スペル**: 文字タイルを順番にタップしてつづりを作る（キーボード入力も可・ヒントあり）。英語ノートと同じ4線の上に文字が並ぶ
- **つかいかた**: 例文の空らんに入る単語を選ぶ。答えたあと、例文全体を読み上げる

### 発音

- ブラウザの音声合成（Web Speech API）で英語（en-US）を読み上げます。ふつう／ゆっくりを選べます
- 対応ブラウザ（Chrome など）では「🎤 いってみよう」で、自分の発音が伝わるかためせます
- カタカナの読みかたは「めやす」として表示します（せっていで消せます）

## 「確実に覚える」ためのしくみ

- **すぐに確かめる**: 新しいことばは、カードで見たあと同じレッスンの中で「見てわかる」問題と「書ける・使える」問題の2回出ます
- **まちがえたら、もう一度**: まちがえた問題は数問あとにもう一度出ます
- **わすれかけたころに復習（間隔反復）**: 1回のレッスンで全問正解したことばは、次に出る日が 1日後 → 3日後 → 7日後 → 14日後 → 30日後 と延びていきます。まちがえると最初からやり直し
- **だんだんむずかしく**: 覚えはじめは選ぶ問題、覚えてきたらスペルや穴うめが多くなります
- **続ける楽しさ**: ⭐、れんぞく日数、シール、紙ふぶき、効果音

3段階進むと「おぼえた」シール、5段階進むと金のシールになります。

## ファイル

- `index.html` … 画面のわく
- `style.css` … 見た目（ライト／ダークの両方に対応）
- `words.js` … 小学生レベルの単語データ（18カテゴリ・317語。単語・意味・絵文字・読みかた・例文・例文の訳）
  - `words` … きほんの118語（先に出る）
  - `more` … ステップ2の199語（曜日・月・時間・スポーツ・のりもの・まちなども）
- `words-levels.js` … 中学生・高校生・大学生レベルの単語データ（`[英単語, いみ, 絵文字, 例文, 例文の訳]`。読みかたはなし）
- `app.js` … アプリの動き

記録はブラウザの `localStorage` に保存されます（端末ごと・ブラウザごと）。

## 単語をふやすには

小学生レベルは `words.js` の各カテゴリの `words`（きほん）か `more`（ステップ2）に、中学生〜大学生レベルは `words-levels.js` の各カテゴリの `words` に1行足すだけです。同じ単語を2つのレベルに入れないでください。

```js
['dog', 'いぬ', '🐶', 'ドッグ', 'I have a dog.', 'わたしは いぬを かっています。'],
```

例文には、その英単語をそのままの形で入れてください（「つかいかた」問題で空らんにするため）。曜日や月のように大文字ではじまる単語は、大文字のまま書けばスペル問題も大文字で出ます。
